# 临时生产权限管理规则（演示制度）

- Policy ID：`PROD-ACCESS-POLICY`
- Version：`2026.08-demo.1`
- 性质：PolicyFlow 第二场景的本地演示制度，不代表任何真实企业或云厂商规则。

## PA-01 申请信息完整性

临时生产权限申请必须绑定申请人、工单、目标系统、权限级别、业务理由与有效时长；任一字段缺失时不得创建授权。

## PA-02 最小权限与时限

生产权限必须采用按需、临时和最小权限原则。普通临时授权最长八小时；超过八小时的申请必须阻断并重新拆分。

## PA-03 双角色批准

生产环境的 operator 或 admin 权限属于高风险写入，创建授权前必须同时取得 System Owner 与 Security Reviewer 的具名批准；执行 Agent 不得自批。

## PA-04 批准参数绑定

批准必须绑定同一 Run、计划、检查点以及申请人、系统、环境、权限级别和时长的参数快照；实际执行参数变化时原批准失效。

## PA-05 独立结果验证

授权后必须由非执行 Agent 独立查询规范状态，核对授权对象、权限级别、有效时长与执行回执；验证失败时不得确认成功。

## PA-06 拒绝、撤权与审计

审批拒绝或验证失败时必须撤销待处理请求或已激活授权，生成幂等撤权回执，并将制度证据、批准记录、执行和验证结果写入审计包。
